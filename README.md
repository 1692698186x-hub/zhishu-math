# 知数 · 数学能力提升

从「发现不会」走向「帮助学会」的七年级数学原型。先了解起点，再根据作答证据安排错因小检查、针对性提示、分层巩固与独立复测。

**当前版本：v0.2.1。** 蓝白配色、精简布局，完整保留学习流程和记录。默认使用本地规则指导；真实 AI 服务的接入已准备好，尚未配置或验证真实模型。

## 直接体验

- [在线体验](https://1692698186x-hub.github.io/zhishu-math/)：静态版使用本地指导，记录留在访问者自己的浏览器。
- 下载项目后，双击 `dist/index.html`，无需安装依赖。
- 运行模型服务接入：安装 Node.js 20 或更新版本，双击「启动知数.cmd」，或运行 `node server.cjs`，再打开 `http://127.0.0.1:8787`。

在线版、本地服务版与本地文件版属于不同地址，各自保存学习记录。切换前可导出记录；当前不提供账号同步和记录导入。

## 新版怎样使用

1. 在「能力提升」中开始「一元一次方程」。
2. 先做 3 道起点短测，覆盖去括号、等式变形、综合解方程。
3. 卡住时写一个关键步骤，用独立小题确认是否需要补某一步。
4. 进行基础、标准、进阶三层练习；同层两道未见新题独立通过后才升级。
5. 在新情境中独立复测，查看学习报告，隔日换题复习。

可随时暂停，刷新后继续同一道题。学生档案各自独立。原有「自适应测评、能力报告、针对性练习、答题记录」继续保留。

首页突出单元、范围和开始入口。答题时可展开「添加关键步骤」「选题依据与最近记录」；「还没学过」等操作收在「其他情况」，完整解法在获取提示后可从该菜单查看。学习规则、指导状态和来源说明均保留在可展开区域。

## AI 的具体作用

真实 AI 接入后，读取当前题目、答案和关键步骤，提出错因假设与下一步提示。推测需要小题验证；模型不能改变判题结果、直接升级或宣布掌握。

- 未配置：显示「本地指导」。
- 已配置并主动开启：请求服务端 `/api/coach`。
- 实际调用成功：才显示「AI 指导已连接」。
- 调用失败：说明情况并使用本地指导，保留进度。

密钥只存放在本机服务端的 `.env.local`，不会进入网页或仓库。见 [AI 接入说明](AI接入说明.md)。GitHub Pages 是静态演示，不运行模型服务。

## 证据和内容边界

辅助作答、重复巩固、新题独立通过分开记录。题面相同，即使编号不同，也不算新的独立证据。复测和后续复习只使用未展示题面；不足时会明确停止。

新增单元包含 240 道模板实例，已校验数值答案、方程代入和结构，**仍待学科教师审核**。原测评保留 531 个知识点、909 条先修边、2271 道上游题目，其中七年级 119 个知识点、524 道题；上游内容为 AI 初稿，也未经教师审核。

结果反映单元作答表现，不是标准化学习能力分数。尚未开展真实学生教学效果实验；程序测试不能证明能提分。

## 开发和验证

应用运行不需要额外包；离线界面模拟测试使用开发依赖 `linkedom`。

~~~sh
pnpm install --frozen-lockfile
pnpm test
pnpm run build:pages
~~~

不安装开发依赖也能运行核心检查：

~~~sh
node tests.cjs
node learning-tests.cjs
node server-tests.cjs
node build.cjs
~~~

`node ui-tests.cjs` 在内存 DOM 中执行真实页面脚本，覆盖短测、小检查、提示、暂停续学、完整报告和档案隔离，不代替真实浏览器外观、手机布局和交互验收。模型服务检查使用测试替身，未调用真实模型。

## 项目结构

| 文件 | 作用 |
| --- | --- |
| `source/learning-unit.js` | 单元、讲解、小检查与练习 |

| `source/learning-ui.js` | 能力提升界面 |
