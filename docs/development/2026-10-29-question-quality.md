# v0.6.5 题库质量审计

本轮覆盖一到九年级531个知识点的2271道源题，逐类审读题干、答案、选项及考查目标。语义审读由AI完成，不代表教师背书或标准化题目质量评估。

## 修复范围

- 修订521道源题，涉及205个知识点。比较大小、方向辨认、分类、平均数、方程、通分、约分、图表等题回到对应学习目标。
- 近似数与简易方程题要求完成最终结果，去掉题干内直接给结论或只让学生填写无关中间步骤的设计。
- 修复一处三角形条件不可行：原周长18、内切圆半径3不可能同时成立；改为周长36、半径3，可由9、12、15的直角三角形实现，面积54。
- 消除旋转题包含零旋转、圆周等分点顺序不明、概率试验被描述成确定性收敛、选择题包含多种真实表述等歧义。
- 29道原短答/自评题改为同目标的选择或数值题，使所有源题可以进入普通与AI练习。保留原文供复核。
- 原题与修订理由见同目录`2026-10-29-question-revisions.json`；新的每条作答记录保存题目内容版本。

## 检查边界

1. `curriculum-tests.cjs`遍历2876道规范练习题，确认运行、参考答案接受性及531点短任务路径。这是工程检查。
2. `question-audit.py`独立于应用判题器，使用精确分数和标准数学函数重算原始/当前核验表达式；另从严格识别出的题面提取运算和单位换算，执行几何条件可行性和线性方程核验。原始、当前、题面三类可能检查同一道题，不可将检查次数相加当成独立题数。
3. `quality-tests.cjs`独立计算全部补充算术、相反数、绝对值和线性方程模板；检查精度、约分、百分号、旧成绩、复习任务、跨版本会话和页面草稿。
4. 现有3960组受控变式参数与1440组方程检查继续保留。题目难度仍为实验等级，未用学生数据校准。

数学表达式检查无法证明文字条件和教学目标正确，因此同时保留AI逐类内容审读及修订记录。尚未完成教师审核和真实学生效果验证，不能称为全题库经过独立专家认证。

## 本机复现

在项目根目录安装既有Node依赖后运行：

```text
node build.cjs
pnpm test
python question-audit.py
```

Python脚本只依赖标准库。GitHub持续检查同时运行它；不需要将Python加入应用服务依赖。
